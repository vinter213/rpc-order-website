RPC • RedPad Creator — удаление системы аккаунтов

КАК ИСПОЛЬЗОВАТЬ
1. Скачай исходники rpc-order-website с GitHub (Code -> Download ZIP) и распакуй.
2. Распакуй СОДЕРЖИМОЕ этого архива прямо в корень rpc-order-website,
   где находятся index.html и app.js.
3. Дважды нажми APPLY_REMOVE_ACCOUNTS.bat.
4. Скрипт сам создаст резервную копию старых файлов.
5. После надписи "Система аккаунтов удалена" загрузи изменённые файлы в GitHub.

ЧТО УДАЛЯЕТСЯ
- кнопки входа на ПК и телефоне
- окно входа / регистрации
- OTP
- Discord OAuth для RPC-аккаунтов
- личный кабинет
- аватары аккаунтов
- accountId/accountEmail/accountName/accountAvatar в формах
- auth.js
- AUTH_SETUP.txt
- SUPABASE_ACCOUNT_SETUP.sql
- загрузка фотографий к отзывам (она была привязана к аккаунтам)

ЧТО ОСТАЁТСЯ
- создание заказов
- Telegram-контакт
- обычные отзывы
- портфолио
- статистика
- Cloudflare Turnstile
- публичное подключение Supabase для данных сайта

ВАЖНО
auth-config.js не удаляется полностью: после обработки в нём остаются только
публичные Supabase URL + Publishable Key, которые нужны портфолио/публичным данным.
Это уже не система аккаунтов.

Если что-то пойдёт не так, рядом автоматически появится папка:
