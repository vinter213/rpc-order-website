RPC ORDER WEBSITE NEON PRO - NO FOLDER VERSION
==============================================

Эта версия без папки assets, чтобы проще загрузить в GitHub через Upload files.

Загрузи в корень репозитория все файлы:
- index.html
- styles.css
- script.js
- config.js
- rpc-avatar.png
- README_RU.txt

В Render Static Site:
Root Directory: пусто
Build Command: echo no build
Publish Directory: .

Если ссылка сервера другая, поменяй её в config.js:
window.RPC_API_URL = "https://rpc-team-crm.onrender.com";
