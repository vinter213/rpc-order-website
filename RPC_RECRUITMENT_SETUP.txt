Серверная функция уже развернута в Supabase проекте rpc-website:

Чтобы заявки начали приходить в Discord, открой Supabase Dashboard -> rpc-website -> Edge Functions -> Secrets и добавь:

DISCORD_BOT_TOKEN=токен_бота
DISCORD_PUBLIC_KEY=public_key_приложения
DISCORD_RECRUITMENT_CHANNEL_ID=id_канала_для_заявок
DISCORD_STAFF_ROLE_IDS=id_роли1,id_роли2,id_роли3

Токен Discord НЕ добавляй в GitHub и НЕ вставляй в recruitment.js.
