ПОМОЩЬ

Частые вопросы

Основные юридические и рабочие условия находятся на отдельном сайте правил.

Когда начинается работа?+

После обсуждения задачи, согласования стоимости и получения предоплаты.

Сколько правок входит в заказ?+

Две небольшие правки. Серьёзные изменения и полная переделка считаются отдельно.

Можно заказать Quest-версию?+

Да. Quest-портирование можно выбрать отдельной категорией или добавить к основному заказу.

Куда приходит заявка?+

На статической версии GitHub Pages текст заявки открывается в Telegram для отправки владельцу @ViNter294. Позже можно подключить внешний API вашего бота.

Можно получить Unity-проект?+

Да, когда это заранее согласовано и не нарушает лицензии используемых ассетов.
