RPC Orders — GitHub/Render production build

FILES TO UPLOAD TO THE ROOT OF THE WEBSITE REPOSITORY:
- index.html
- styles.css
- app.js
- loader.js
- rpc-avatar.png
- rpc-cinematic-bg.webp
- site-preview.png

UPDATE STEPS:
1. Open the GitHub repository used by rpc-order-website.onrender.com.
2. Upload all files from this archive to the repository root.
3. Confirm replacement of files with the same names.
4. Commit changes to the main branch.
5. Wait until Render shows "Your site is live".
6. Open the website and press Ctrl+F5.

The archive contains the production API connection, Turnstile, Supabase statistics,
reviews, RU/EN and automatic currency selection. Local mocks and local launch
scripts are not included.
