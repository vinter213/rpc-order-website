RPC SITE GATE — проверка перед входом на сайт

Что добавлено:
1. Полноэкранная проверка Cloudflare Turnstile перед показом сайта.
2. Сайт открывается автоматически после успешной проверки.
3. Результат хранится только в текущей вкладке браузера через sessionStorage.
4. Отдельная проверка в форме заявки сохранена.

Что заменить:
В index.html теперь есть ДВА места с:
PASTE_TURNSTILE_SITE_KEY_HERE

Оба места нужно заменить на один и тот же Cloudflare Turnstile Site Key.

Где должен быть Secret Key:
Secret Key не вставлять в HTML.
Он должен быть только в Render backend CRM:
TURNSTILE_SECRET_KEY=...

Важно:
Эта входная проверка закрывает сайт визуально на frontend.
Для настоящей серверной защиты заявок всё равно нужна проверка токена в backend /public/order.
Если нужна прям жёсткая защита до загрузки сайта, подключай свой домен к Cloudflare и ставь WAF Challenge/Access на домен.
